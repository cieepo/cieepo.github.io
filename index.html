JARVIS – a personal assistant app

JARVIS is a private personal assistant built and operated by one individual, Jonatan, as a tool for their own personal and professional use. It runs on a computer at the developer's home and is used from the developer's own phone and computer. It is not a public service and is not offered to other people.

Under development. JARVIS is not a finished assistant yet. It is not available for download or sign-up. The sections below separate what has been tested from what is only planned.

Tested so far

Technical tests of building blocks. None of them reads the content of an email message.

  • Secure access from the developer's phone to the home server through an encrypted private network.
  • Speech recognition running locally on the home server.
  • A technical connection to Anthropic's Claude models.
  • Push notifications to the developer's phone.
  • Signing in with the developer's own Google account, and a daily check that the access token still works (it reads only the basic Gmail profile, no messages).
  • A test in which JARVIS sent one email to the developer's own address and found it again through its headers, without reading any message content.

Planned – does not work yet

These are the features JARVIS is being built to provide. They are not available yet:

  • Email – with the developer's explicit permission through Google sign-in: searching and summarising the developer's own Gmail messages, preparing draft replies, and sending or organising messages only on the developer's instruction.
  • Calendar, tasks and notes – planning the day, keeping to-do items and notes, reminders about deadlines.
  • Conversation and voice – talking to the assistant by text or voice, with answers generated by Claude models and spoken answers produced by a text-to-speech service.
  • Encrypted backups of the app's own data.

Google user data

The developer has signed in to JARVIS with their own Google account and granted it access to their own Gmail account (Gmail API scopes gmail.modify and gmail.send). So far this access has been used for a daily check that it still works (basic profile only) and for one test message sent to the developer's own address, with no message content read. The permissions are meant to provide the planned email features. Google user data will be used only to provide these user-facing features to the account holder. It is not sold, not used for advertising, and not used to train AI models. The Privacy Policy describes exactly where the data goes and how it can be deleted.

JARVIS's use of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
